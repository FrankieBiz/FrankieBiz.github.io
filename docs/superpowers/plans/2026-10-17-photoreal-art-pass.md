# Photoreal Art Pass — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lift the launch-to-orbit portfolio from "clean real-time graphics" to cinematic photoreal by replacing procedural geometry with authored Blender assets and adding film-grade lighting, atmosphere and camera effects — without breaking the frame budget on Intel integrated graphics.

**Architecture:** A reproducible asset pipeline (Blender Python scripts → glTF → glTF-Transform compression → `public/assets/`) feeds a loader that swaps the procedural rocket/pad for authored models, with the current procedural scene kept as an automatic fallback. Rendering gains baked lighting, scene-rendered HDR environments, a simulated-smoke flipbook, real NASA Earth imagery, and an expanded post stack (ambient occlusion, depth of field, light shafts, colour grading, lens dirt, heat shimmer), each gated by quality tier.

**Tech Stack:** Blender 5.2 (headless `bpy` scripts, Cycles baking, Mantaflow), glTF-Transform CLI 4.5 (meshopt + WebP), three 0.186 (GLTFLoader, MeshoptDecoder, HDRLoader, LUTCubeLoader), postprocessing 6.39 (DepthOfFieldEffect, GodRaysEffect, LUT3DEffect, SMAAEffect), n8ao 2.0.1, sharp (image processing), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-17-rocket-portfolio-design.md` (this plan upgrades §2 Art Direction and §4 Architecture; acts, copy, interaction and fallbacks are unchanged).

## Global Constraints

- Direction: **cinematic photoreal** (chosen 2026-10-17). Palette stays near-monochrome navy/frost; ignition orange only from fire, beacons and city lights.
- Reference hardware: **Intel Panther Lake integrated graphics** (owner's laptop). Medium tier must hold ~60 fps at 1440×900, DPR ≤ 1.5.
- Download budget (first load, compressed): **high ≤ 15 MB, medium ≤ 10 MB, low/mobile ≤ 6 MB**. JS stays ≤ 300 KB gzip.
- Texture caps: high 2K (planet 4K), medium 2K, low 1K. No texture larger than 4096 px.
- Every asset is original (generated by our scripts) or CC0 / NASA public imagery with credit. No third-party logos, no real-vehicle likeness.
- Fallbacks stay: no-WebGL static site, reduced motion, and **procedural scene if any asset fails to load**.
- Content swap points unchanged: `src/content/projects.ts`, `src/content/site.ts`.
- Asset builds are reproducible: `npm run assets` regenerates everything from scripts + downloaded sources.

## Review Focus

1. **Slow or failed asset downloads** — a visitor on hotel Wi-Fi must still get a working site: the loader shows byte progress, and a 404, corrupt file or >20 s stall falls back to the procedural scene (tested in Task B12 by aborting asset requests in Playwright).
2. **GPU memory on phones and integrated GPUs** — 4K textures can crash mobile Safari: the tier picks texture sizes, and the manifest test (Task B1) fails the build if any low-tier texture exceeds 1K.
3. **Effects stacking past the frame budget** — AO + DoF + light shafts together on medium tier: each effect has a per-tier switch, and Task B14 records frame times on the owner's hardware before any effect ships on by default.
4. **Reduced motion** — depth-of-field pulls, heat shimmer and camera shake must stay off under `prefers-reduced-motion` (asserted in the QA suite, Task B15).
5. **Context loss with larger GPU payloads** — the existing reload-and-resume path must still work with loaded models and HDR textures (QA suite forces `WEBGL_lose_context`, Task B15).

## File Structure

```
tools/
  blender/
    common.py           shared helpers: scene reset, materials, bake, export
    rocket.py           authored rocket → assets-src/rocket.glb (+ preview render)
    pad.py              tower, mount, trench, floodlights; baked lightmaps → assets-src/pad.glb
    environment.py      renders pad + orbit equirect HDRs → assets-src/env-*.hdr
    smoke.py            Mantaflow sim + Cycles frames → assets-src/smoke/*.png
  lut/make_lut.py       generates the colour grade → public/assets/grade.cube
  textures/lens_dirt.py procedural lens-dirt texture → public/assets/lens-dirt.webp
scripts/
  fetch-nasa.mjs        downloads NASA imagery into assets-src/nasa/ (verified URLs, see Sources)
  build-assets.mjs      compresses assets-src/ → public/assets/ (meshopt + WebP, per-tier sizes)
src/
  assets/manifest.ts    every asset: url, bytes, tier sizes, required/optional
  assets/load.ts        byte-progress loader with timeout + fallback signal
  scene/RocketModel.ts  wraps the GLB rocket (same interface as procedural Rocket)
  scene/PadModel.ts     wraps the GLB pad (arms, beacon, lights by node name)
  scene/SmokeFlipbook.ts flipbook smoke material (replaces puff sprites)
  post/Grade.ts         LUT + lens dirt + anamorphic streak
  post/HeatShimmer.ts   flame-masked screen distortion
  (modified) post/PostFX.ts, scene/World.ts, scene/Planet.ts, scene/Exhaust.ts, director/state.ts, director/timeline.ts, main.ts
tests/
  manifest.test.ts      tier budgets, sizes, required assets
  flipbook.test.ts      frame index / blend maths
  lut.test.ts           generated .cube is valid and monotonic
assets-src/             (git-ignored) raw sources and Blender outputs
public/assets/          compressed, shipped assets
```

`assets-src/` is git-ignored (large, reproducible); `public/assets/` is committed so the site deploys without Blender in CI.
